# Hako Devices

Line drawings and 3D views of computers, that you drop into a page and assemble from parts.

- [Build from parts](parts.md): the description, every part, every fit rule, presets.
- [The element](element.md): `<hako-device>`, its attributes, events and live screen, and the React wrapper.
- [To scale](scale.md): real size, `<hako-lineup>`, the ruler, and what a drawing records.
- [Styles](styles.md): `thin`, `thick`, and how to add one.
- [Assets](assets.md): the shipped files and how to use them on their own.
- [Wishlist](wishlist.md): machines still to come. Each has a name and the one "Coming soon" picture until it is built for real.
- [Machine list (JSON)](machines.md): every machine as one static file, from npm and from the demo site, with its fields. It is regenerated whenever machines are added.
- [Building machines](building-machines.md): how to add a machine to the same standard, with prompts for a coding agent.
